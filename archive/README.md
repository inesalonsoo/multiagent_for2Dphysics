# archive/

Superseded artifacts, kept for the record. None of this is part of the
current pipeline: see the root `README.md` and `PROJECT_STATE.md` for that.
The full history is in `docs/HISTORY.md`.

## results/phi_single_point_trajectory.png, results/phi_switching_check_long_run.png

Diagnostic plots from an early attempt to show switching directly on the
2D stochastic Allen-Cahn field at domain size L = 10. They show no barrier
crossings even over long runs. This is why the checkable benchmark moved
to the 0-D double well (Phase 1) and the 2D field became Phase 4.

## results/phase3_convergence_study_v1_prompt_anchored/

The first, 8-run version of the Phase 3 study. Every run proposed the same
config on its first try, because the Optimizer's prompt contained the
answer. This led to the redesigned prompt used in the current study
(`results/phase3_convergence_study_report.md`).

Nothing in `archive/` is regenerated by a script or imported by a module.
