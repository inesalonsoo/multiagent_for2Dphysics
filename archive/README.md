## results/phi_single_point_trajectory.png, results/phi_switching_check_long_run.png

Diagnostic plots from the abandoned pre-pivot attempt to demonstrate
switching directly on the 2D stochastic Allen-Cahn field at domain size
L=10 (Sessions 2 and 4, before the Phase 1/Phase 4 pivot — see
`PROJECT_STATE.md` §9's 2026-07-11 entry). Both show zero committed barrier
crossings even over long runs; this negative result is exactly what
motivated moving the primary verified benchmark to the 0-D double well
instead (where the Eyring-Kramers rate's exponent is exact and its
prefactor asymptotically exact, and the Boltzmann ratio is exact by
symmetry) and demoting the 2D field to Phase 4, targeting a much
smaller domain (L=2.5) not yet attempted. Kept because they're the direct
evidence behind that pivot decision, not because they're current results.

## results/phase3_convergence_study_v1_prompt_anchored/

The first (8-run) version of the Phase 3 agentic convergence-robustness
study. Every one of its 8 real-LLM runs proposed the byte-identical
config on the first try, because the Optimizer's prompt handed it the
already-converged answer directly — an honest negative finding (the
Validator's gate was never exercised against a genuinely wrong config),
not a bug. This is what led to redesigning `agents/optimizer.py`'s
`SearchBounds` to hand the Optimizer only the search space, never the
solved value, and re-running the study (the current `results/
phase3_convergence_study_report.md` and `results/phase3_convergence_study/`
are that redesigned, v2 run). Full diagnosis in `PROJECT_STATE.md` §9.
